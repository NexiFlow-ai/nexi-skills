# Nexi Skills — українською

Це дзеркало репозиторію українською: [посібник](./guide/README.md), [формат пака](./SPEC.md), [реєстр](./REGISTRY.md).
Файли самого пака (`../packs/nexus-base/`), інструменту (`../toolkit/`) та схеми — спільні для обох мов.

## Що тут є

| Шлях | Що це |
|---|---|
| [`guide/`](./guide/README.md) | **Посібник** — від того, що таке пак, до власних агентів у розгортанні Nexi: навички, агенти, Flow, шар blueprint, пісочниця, практики, яких дотримується сама платформа, рецензія, підпис, реєстрація. |
| [`../packs/nexus-base/`](../packs/nexus-base/README.md) | **Nexi Base**, еталонний пак — відрецензовані навички, агенти, Flow, патерни, політики, профілі пісочниці та шаблони дашбордів, з яких починає кожна організація. [`CATALOGUE.md`](../packs/nexus-base/CATALOGUE.md) перелічує, що опубліковано і що *готується*. Підписаний видавцем Nexi; перевірте самі через `nexi-pack verify`. |
| [`../toolkit/`](../toolkit/README.md) | **`nexi-pack`** — validate · digest · sign · verify · `install --dry-run` · `new`. `pip install ./toolkit`. JSON-схеми формату пака — в `toolkit/src/nexi_pack/schemas/`. |
| [`SPEC.md`](./SPEC.md) | Формат пака: маніфест, види ресурсів, дайджести, підпис, канонічний payload. |
| [`../publishers.yaml`](../publishers.yaml) | Публічний ключ видавця Nexi — запис, який оператор розгортання додає, щоб довіряти Nexi Base. |
| [`REGISTRY.md`](./REGISTRY.md) | Реєстр спільноти: паки, які опублікували інші, з ключем видавця — і як додати свій. |

## З чого почати

```sh
pip install ./toolkit
nexi-pack verify packs/nexus-base --publishers publishers.yaml   # еталонний пак — так, як його бачить розгортання
nexi-pack new my-pack                                              # ваш власний: одна навичка, один агент, один Flow
nexi-pack validate my-pack
```

Далі — посібник: [розділ 7](./guide/07-your-first-pack.md) проводить від каркаса до підписаного пака,
[розділ 8](./guide/08-review-sign-register.md) — до розгортання, [розділ 9](./guide/09-best-practices.md) — перелік
правил, яких дотримуються власні паки платформи.

## Чим цей репозиторій не є

Він не є платформою. Сервіси, які виконують пак — розмова, рушій Flow, пісочниця, застосування політик — це Nexi,
комерційний продукт (див. профіль організації). Усе тут під Apache-2.0, щоб пак, який ви пишете, був вашим, працював
у будь-якому розгортанні Nexi, що довіряє вашому ключу, і його міг прочитати, відрецензувати й перевикористати хто
завгодно.
